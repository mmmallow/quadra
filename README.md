# Quadra

Quadra is a small engine for playing Scrabble-like games. Currently, the AI uses the Appel and Jacobson algorithm for solving, however,
in the future I plan to add TD learning.

## Prerequisites

- Python 3.12 (specifically for PyGame, which doesn't support >3.12)

## Installation

'''bash
pip install -r requirements.txt
'''

## Usage
'''bash
python3 main.py
'''
